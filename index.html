Security First

Your Funds Are
Always Safe.

We've built CryptoForge with security as the foundation — not an afterthought.

JWT Authentication

Stateless JSON Web Tokens with configurable expiry. Every API request is verified. No session hijacking possible.

ACID Transactions

Every trade uses SELECT FOR UPDATE pessimistic locking. Concurrent orders never corrupt your balance — guaranteed.

BCrypt Password Hashing

Passwords are never stored in plain text. Industry-standard BCrypt with adaptive cost factor protects every account.

Real-Time Audit Logs

Every login attempt and trade is logged with full details. Complete audit trail for compliance and account security.

Route Protection

All trading and portfolio endpoints require authentication. Admin routes protected with role-based access control.

HikariCP Connection Pool

Production-grade database connection pooling with timeout protection. No connection leaks, no downtime from DB overload.
